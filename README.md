# NOVA PERFORMANCE

**Responsive Fitness & Personal Training Website**

NOVA PERFORMANCE ist eine moderne Website für ein fiktives Fitness- und Coaching-Unternehmen.

Das Projekt entstand im Rahmen meiner persönlichen Weiterbildung in der Frontend-Webentwicklung. Ziel war es, eine realitätsnahe Unternehmenswebsite mit HTML, CSS und JavaScript zu entwickeln und dabei besonders auf Design, Benutzerfreundlichkeit und responsive Layouts zu achten.

## 🚀 Projektübersicht

Die Website präsentiert ein fiktives Unternehmen mit Schwerpunkt auf Personal Training, Online Coaching und individueller Trainingsplanung.

### Inhalte und Funktionen

- Responsive Navigation mit mobilem Hamburger-Menü
- Hero-Bereich mit Call-to-Action
- Übersicht der Trainings- und Coaching-Leistungen
- Darstellung verschiedener Coaching-Angebote
- Kundenstimmen und Erfolgsgeschichten
- Vorstellung des Trainerteams
- Kontaktformular mit Eingabefeldern und Auswahlmenü
- Footer mit Navigation und rechtlichen Hinweisen

## 💻 Projekt lokal starten

1. Repository klonen oder als ZIP herunterladen.
2. Projektordner in Visual Studio Code öffnen.
3. `index.html` im Browser starten.

Es sind keine zusätzlichen Abhängigkeiten erforderlich.
